# 📰 News Room – React News App

A modern **News Web Application** built with **React + Vite** that displays the latest news by category using a News API.

## 🚀 Live Features

* 🗂 Category based news (Business, Sports, Technology, etc.)
* 🌙 Dark / Light Theme
* 🌍 Country-based news support
* ⚡ Fast loading with **Vite**
* 🔄 React Router navigation
* 📱 Responsive UI

---
## 🛠 Tech Stack
* **React JS**
* **Vite**
* **React Router**
* **Context API**
* **News API**
* **Tailwind CSS / CSS**

## ⚙ Installation

Clone the repository
```

```

```
npm install
```
Run the project
```
npm run dev
```
